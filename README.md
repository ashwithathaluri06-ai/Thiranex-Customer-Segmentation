# Customer Segmentation

## Internship Project
This project was completed as part of my Data Analytics Internship at Thiranex.

## Project Overview
The project analyzes customer demographics and purchasing behavior to identify meaningful customer segments.

## Dataset
The dataset contains:
- CustomerID
- Gender
- Age
- Annual Income
- Spending Score
- Preferred Category

## Analysis Performed
- Customer demographic analysis
- Spending behavior analysis
- Income and spending pattern analysis
- Customer segmentation
- Segment-wise comparison and visualization

## Tools Used
- Microsoft Excel
- Power BI
- Data Analysis & Visualization

## Project Result
The analysis helps identify different customer groups based on demographic characteristics and spending behavior, supporting better customer targeting and business decision-making.
